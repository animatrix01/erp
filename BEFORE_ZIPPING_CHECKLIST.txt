💡 HOW TO CREATE THE ZIP:
-------------------------

Windows:
1. Delete node_modules and .next folders
2. Right-click on "erp-main" folder
3. Choose "Send to" > "Compressed (zipped) folder"
4. Share the ZIP file

Or use Git (cleaner):
> git archive -o erp-main.zip HEAD
